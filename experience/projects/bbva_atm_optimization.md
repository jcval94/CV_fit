# BBVA — ATM Placement and Relocation Optimization

## Executive summary

Optimization initiative designed to improve ATM placement / relocation decisions using customer consumption, mobility and location-related patterns rather than relying only on static network criteria.

## Business problem

ATM infrastructure decisions have a material operating cost. Placement or relocation should account for actual customer behavior, usage patterns and geographic context rather than treating all locations as equivalent.

## Objective

Identify stronger ATM placement / relocation candidates by combining customer and network signals into a repeatable analytical decision framework.

## José Carlos's ownership

- translated infrastructure-placement decisions into an analytical optimization problem
- integrated customer consumption / mobility signals with location context
- developed prioritization logic for candidate locations
- compared alternatives using business-impact criteria
- translated model outputs into recommendations usable by operational stakeholders
- communicated estimated benefits, assumptions and limitations
