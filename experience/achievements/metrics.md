# Validated Achievement Metrics

Canonical registry of quantified professional achievements.

Each metric should include:

- project or role source
- metric name
- baseline
- resulting value or delta
- unit
- time period
- business context
- validation/source notes
- approved wording for CV use

> Metrics should only be added when the numerator, denominator, comparison period and interpretation are understood well enough to defend in an interview.
