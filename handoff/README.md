# Work final-review handoff

This directory is generated by the CV pipeline.

Each vacancy package contains the exact material needed for a final ChatGPT Work review:

- `vacancy.md` and `vacancy.json`
- `cv_proposed.json`
- `cv_proposed.html`
- `html_base.html.j2`
- `prompt.md`
- `handoff.json`

A final reviewer writes `final.html` and `review_notes.md`. The `Final CV render` GitHub Action then creates `final.pdf`, `final.png`, and `final_report.json`.

`index.json` is the queue for scheduled final-review work. Pending candidates are listed before finalized ones and contain direct repository/download links.
